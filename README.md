## Featured Work

### [Hifadhi — CodeGreen Kenya AI Challenge](https://github.com/Deo-Siatah/CodeGreen-kenyaAiChallenge)
An alternative agricultural credit-scoring platform built for the **Kenya AI Challenge** (Mercy Corps AgriFin track, AFRACA "Invisible Farmer" brief). Hifadhi builds a credit profile for smallholder farmers from evidence that already exists in rural communities — community testimony, buyer and agrovet relationships, Chama/SACCO discipline and satellite-derived farm activity.

It produces a deterministic, auditable score with a full component breakdown, a loan recommendation and a plain-language explanation in English or Kiswahili, backed by a live trust graph and portfolio analytics.

**Stack:** Python · FastAPI · React · Trust Graph · Explainable AI

### [Hasibu — Value4money Agent](https://github.com/Deo-Siatah/QHALA_Value4money-agent-V2)
A procurement intelligence agent that turns a public tender and its bids into a sourced evidence file for the committee that has to decide on it — in minutes, not half a morning. Every bid is compared against years of comparable public awards, arithmetic is verified against line items, and gaps in evidence are named instead of guessed.

**Stack:** Python · LLM Agents · Document Extraction · Retrieval

### [Agri Assistant](https://github.com/Deo-Siatah/Agri-assistant-RAG)
A production-style agricultural advisory platform for location-aware crop guidance and document-grounded farm decision support. Answers farmer questions from indexed PDF knowledge bases, analyses agronomic CSV datasets, checks live weather for Kenyan counties, and serves contextual recommendations through a full backend and frontend.

**Stack:** FastAPI · PostgreSQL + pgvector · Redis · Groq · Open-Meteo · Vite + React

### [Smart Study Recommender System](https://github.com/Deo-Siatah/SMART-STUDET-RAG-SYSTEM)
A RAG-powered learning assistant that ingests lecture notes and past papers, then answers strictly from the student's own study material — with Tutor, Revision and Exam modes, conversational memory, insufficiency detection and full retrieval traceability.

**Stack:** Python · RAG · Vector Embeddings · Conversational Memory

### [Smart Chef Agent](https://github.com/Deo-Siatah/smart-chef-Agent)
An AI recipe agent that turns leftover ingredients into practical meals while respecting allergies, dietary preferences, nutrition goals and ingredient freshness. It searches, filters unsafe options, ranks matches and asks the user to choose before returning full instructions.

**Stack:** LangGraph · Groq · Spoonacular · Tavily · FastAPI · PostgreSQL

### [Nana Care](https://github.com/Deo-Siatah/NANA-CARE-APP-)
A full-stack platform empowering Kenya's domestic workers — house managers and mama fuas — by connecting them with trusted employers, offering training resources and giving them visibility, stability and fair working opportunities. Aligned with SDG 8, SDG 5 and SDG 10.

**Stack:** React · Node.js · JWT Auth · PostgreSQL · Vercel

### [Notification Platform](https://github.com/Deo-Siatah/Notification-platform)
A production-grade notification system handling email and SMS delivery at scale — queue-based processing, feature flags with gradual rollout, structured logging, idempotency, rate limiting, Prometheus metrics and graceful shutdown.

**Stack:** Node.js · Express · Bull + Redis · PostgreSQL · Twilio · Docker · Prometheus

### [Icebreaker — Connect Human](https://github.com/Deo-Siatah/ice-breaker-hackthon)
A premium, frontend-only event networking experience that helps people discover who they should meet before starting a conversation. Built for craft — every animation, transition and interaction is intentional.

**Stack:** TypeScript · React · Motion Design

### [Personal Portfolio 3.0](https://github.com/Deo-Siatah/MYPROFPORTFOLIO3.0)
My personal site: a polished landing page, a filterable project archive with detail pages, a live skills visualization and an authenticated admin area for managing content.

**Stack:** React 19 · TanStack Start · TanStack Query · Tailwind CSS 4 · Supabase · Recharts

## How I Build

| Principle | What it means in practice |
|---|---|
| **Ship end-to-end** | Backend, frontend, data, deployment and integration — not just a demo layer |
| **Ground the model** | Retrieval, traceability and insufficiency detection over confident guessing |
| **Design for failure** | Queues, retries, caching, idempotency and observability from day one |
| **Protect the user** | Authorization, data minimisation and privacy-reduced explainability by default |
| **Build for real people** | Farmers, students, workers, committees — solutions measured by who they help |

**I'm not just trying to publish code. I'm trying to build systems that hold up in the real world.**
